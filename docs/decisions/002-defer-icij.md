# ADR 002: Defer ICIJ Offshore Leaks

- **Status:** Superseded (2026-10-19). The user chose to include ICIJ; it is downloaded and in scope for Phase 1.
- **Original decision:** Build on IBM AML HI-Small plus OpenSanctions only and defer ICIJ.
- **Why it was reversed:** The archive is 72 MB compressed (626 MB unzipped), which is small enough for a
  laptop. ICIJ adds offshore company and officer links that OpenSanctions does not cover.
- **Still applies:** ODbL share-alike terms cover any derived database that is publicly used, so do not
  publish derived ICIJ data. Inclusion in the database does not imply wrongdoing.
